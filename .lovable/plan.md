# Tab-Icons auf /de/elster tauschen

In der Tabsleiste des Logins:

- **Steuernummer** bekommt das Icon, das aktuell beim **E-Mail Login** steht.
- **E-Mail Login** bekommt das Icon, das aktuell beim **Personalausweis** steht.
- Personalausweis behält sein Icon (es wird nur kopiert, nicht entfernt).

## Technisch

In `src/pages/Elster.tsx` die `icon`-Werte der jeweiligen Tab-Einträge entsprechend austauschen. Keine weiteren Änderungen.
